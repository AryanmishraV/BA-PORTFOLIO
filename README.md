## 📂 Project Structure

Each project follows a consistent BA workflow:

```
Business Problem → Data → SQL Analysis → Python Analysis → Report + Visuals
```

```
project_folder/
├── data/           ← CSV dataset
├── sql/            ← SQL file (8–10 analytical queries)
├── analysis/       ← Python analysis script (Pandas)
├── visuals/        ← Charts generated from analysis
└── report/         ← Auto-generated output CSVs
```
